# 文本怎么写

停顿和读音标注需开启高级功能。下面的文本可直接复制。

## 短暂停顿：两个空格，200 ms

```text
准备好了。  开始吧。
```

## 多停一拍：三个空格，300 ms

```text
请记住。   安全第一。
```

## 句间停半秒：换行，500 ms

```text
第一句说完。
再说第二句。
```

## 缩写逐字母读：字母之间留一个空格

```text
请检查 C P U 的使用率。
```

## “银行”的“行”读 háng

```text
我去银<行|HANG2>办业务。
```

## “行走”的“行”读 xíng

```text
请沿人<行|XING2>道<行|XING2>走。
```

## 日语“上手”读じょうず

```text
彼は料理が<上手|じょうず>だ。
```

连续普通空格每个计 100 ms，从两个起生效；与换行相邻时取最长停顿，不累加。
不要写 `[悲伤]`、`<emotion=happy>` 或 `<|en|>`：它们不是控制标签，可能被读出来。
当前不支持用文本标签逐段指定情绪，或给某个字词加重；`**重点**`、`[强调]` 也不是控制指令。
高级功能的自动情绪会按分段内容判断语气，但不保证结果；手动情绪对整次生成生效。
读音标注不保证纠正所有发音。
