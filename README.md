# Local Voice Reader（本地语音生成器）

使用本机模型生成英语语音，支持声音档案、零样本声音克隆和自动/手动情绪控制。创建档案只保存参考录音，不会训练模型；文本和录音不会上传。

## 安装与首次运行

请先按[公共准备说明](docs/install-common.md)安装 Python/uv、下载主模型和预取辅助模型，再选一份与你的设备对应的指南：

- [CPU 版安装](docs/install-cpu.md)
- [GPU 版安装](docs/install-gpu.md)

两种安装共用同一组模型文件，但运行依赖分别安装。平台指南提供最小依赖和可复制的完整命令。生成前必须完成公共说明中的模型文件检查；`start-auto.bat` 会以离线模式启动，不会在生成时补下载模型。

## 使用 Web 界面

启动完成后打开 `http://127.0.0.1:7860`。在 **声音档案** 中上传录音、裁剪到 3–30 秒并创建档案，然后在 **生成语音** 输入文本并生成。声音档案和生成结果保存在被 Git 忽略的 `private-data/` 中。

生成页提供声音、阅读语言、文本、生成 / 取消和音频。**设置** 页提供设备和运行详情；
**声音档案** 页分别管理已保存档案和创建新档案。
Gradio 可翻译的常用控件文案默认显示简体中文，无需在页脚切换。Gradio 5.45.0
仍按浏览器语言选择内部语言，部分未接入翻译的内容（如音频控件的无障碍标签、
排队进度及框架设置面板中的说明）可能显示英文。

网页首次默认**开启高级功能**：启用手动停顿、指定发音和情绪调整，
**文本写法案例** 默认折叠，点击展开查看。
关闭高级功能后使用快速模式，不额外分析情绪、不按用户换行或多空格额外拆块，
发音标注只读原词；命令行仍默认使用快速模式。
浏览器保留开关选择，旧浏览器记录缺少此选项时按开启处理，已保存的关闭选择仍保留。
Qwen 情绪模型只在首次高级自动情绪请求时加载；手动情绪无需自动分析。
静音是音频拼接，不是额外模型推理；增加独立文本块和自动情绪分析才会增加生成成本。
原来的显存安全分段仍生效，快速模式不保证长文本只有一个模型内部片段。

也可以直接选择内置的 **内置男声** 或 **内置女声**，无需上传参考录音。两份英文参考声音
来自允许再分发的 CMU ARCTIC 语料，随程序离线提供；来源与修改说明见
[音频许可](src/voice_reader/assets/LICENSE-CMU-ARCTIC.txt)。内置声音不可重命名或删除，
网页只提供内置男声、女声及用户创建的档案，不再显示 Default Reference 选项；
旧网页记录若选中了该项，会恢复为内置男声。原录音文件不会删除。
在 **声音档案** 页的 **已保存档案** 列表选择用户档案，
再改名或确认删除；该列表独立于生成页的声音选择，打开页面或刷新档案时会重新读取。

生成页的 **阅读语言** 默认为“自动”，支持中文、英语、日语、西班牙语和阿拉伯语。
自动模式在快速模式判断整段，在高级模式按每个显式文本块识别；中文夹英文时选择中文条件，不翻译原文。
专名、短文本或纯汉字日文可能误判，可手动指定朗读语言。
**情绪强度** 首次默认为 **0.4**。刷新网页会恢复当前浏览器、同一站点上次的
文本、声音、情绪模式与类别、强度、语言和设备选择；清除站点数据会清除这些记录。

有可用 CUDA 的机器提供 **自动 / CPU / GPU** 设备选项，仅有 CPU 的机器提供自动 / CPU。
选择在下次生成生效；切换设备会释放旧推理进程，再加载新模型。
**取消生成** 会停止当前浏览器的推理并清理未完成音频，也会取消该浏览器的
排队请求；下一次生成重新加载模型，不能从取消位置续读。修改代码后请重启旧服务。
文件生成完成后，服务器终端输出本轮推理总用时，包含模型加载（如有）、分段生成和文件写入，不含排队等待。
生成后可点击音频播放器右上角的“下载”保存 WAV 文件。

需要安排停顿或纠正读音时，参阅[文本写法案例](docs/speech-tips.md)，
每个场景都给出可直接复制的短文本，也嵌入在网页的高级功能区域。

录音支持 WAV、MP3、M4A 和 FLAC，每个文件最多 100 MiB。请只使用自己或已获准使用的录音。默认 Web 服务只绑定本机，不会创建公开分享链接。

### 断句与停顿小技巧

**先开启高级功能。** 关闭时不应用以下手动断句和静音规则，但不会修改输入框中的原文。

换行或两个及以上连续普通空格是**强制断句标记**。每个非空文本块独立生成，
不会被重新合并成同一段语音。停顿规则如下：

| 输入标记 | 额外插入的静音 |
| --- | --- |
| 单个普通空格 | 不强制断句 |
| 两个连续普通空格 | 200 毫秒 |
| 三个连续普通空格 | 300 毫秒 |
| 四个连续普通空格 | 400 毫秒 |
| 换行 | 500 毫秒 |
| N 个连续普通空格（N >= 2） | N × 100 毫秒，不以 500 毫秒封顶 |

使用建议：紧凑短停顿用两个空格，普通句间停顿可先试三个或四个空格，
换段或希望听众稍作思考时用换行。例如，避免 `R. Fits` 连读：

```text
R is a best-fit estimate, not the planner's R.
Fits require at least three common observed minutes.
```

也可写成 `the planner's R.  Fits require ...`（句号后两个空格）。
单个空格不触发强制断句；连续空行不叠加停顿，混合标记取最长停顿（例如换行
夹着六个空格时取 600 毫秒），首尾空白不产生空音频。模型音频自身可能包含
静音，实际听到的间隔可能比额外插入的静音更长，建议根据试听结果调整。
日志会显示每个显式文本块。网页和命令行、CPU 和不同显存 GPU 的行为一致，
每块内部仍使用原有显存分段。自动情绪会分别分析各块，额外边界可能增加耗时；
强制保证的是独立生成和静音间隔，不是特定句尾语调。粘贴文本时注意多余空格。
修改程序后需要关闭旧服务，再重新启动，网页才会使用最新的停顿规则。

## 小显存 GPU

现有环境安装完成后，直接双击 `start-auto.bat`，打开 `http://127.0.0.1:7860`。
选择已保存的声音档案，再生成语音。网页会显示本次完整生成耗时和实际运行策略。

默认 `--runtime auto`：小于 8 GiB 显存且支持 BF16 的 CUDA GPU 使用 `low-vram`。
该策略将 BF16 GPT 和 FP32 声学/波形模型固定放在 GPU，参考编码和情绪模型固定放在 CPU，
复用同一档案的参考条件，使用 TF32 矩阵乘法和最多 32-token 的文本分段。
不使用 INT8/INT4，不在每个生成步骤搬运模型，也不降低 beam 数或扩散步数。
首次生成包括模型加载和参考编码，之后同一档案更快；切换档案会重新编码参考。

CUDA 分配器限制为显存容量的 90%，为驱动和工作区留余量。遇到显存或语音 token 上限时，
会记录警告并用更小分段重新生成完整请求；仍无法完成则明确报错，不返回已知截断结果，
也不静默切到 CPU。其他应用占用显存仍可能导致失败。
情绪分析也有 token 上限；不正常终止时明确报错。

可通过 Web 或 `speak` 命令的 `--runtime standard` 恢复原来的设备放置和分段策略；
CPU 默认仍使用标准策略。BF16 不受支持时会提示明确选择标准策略或 CPU。
半精度、TF32 和分段可能改变随机采样、语速或韵律，自动检查不能替代最终试听。

### 本机验证结果

RTX A2000 Laptop GPU（4 GiB）上的候选实测：

| 场景 | 小显存策略完整生成耗时 |
|---|---:|
| 同一档案、后续手动情绪短句 | 中位数约 10 秒 |
| 同一档案、后续自动情绪短句 | 约 17.5 秒 |
| 约 180 字符段落、自动情绪 | 约 32 秒 |
| 约 800 字符长文、自动情绪 | 约 97 秒 |

最终策略完成 26 次生成，CUDA 峰值预留约 3.51 GiB；原 GPU 策略的一个短句对照耗时
1558 秒、峰值预留约 9.38 GiB。分段和随机采样会改变音频时长，不能将该极端溢出对照
当作通用加速倍数。网页实际测试通过自动和手动情绪生成，后续手动请求耗时 10.4 秒；
首次网页请求包含初始化，实测约 66.5 秒。

选择性 INT8 GPT + NF4 情绪、NF4 GPT + NF4 情绪在本机测试中均比半精度候选慢，
因此未加入生产依赖。客观评测使用本地独立 ASR 与 WavLM 说话人模型：
8 类配对文本的平均 WER 增加约 0.44 个百分点，低于 1 个百分点验收线。
日期和金额的等价表达造成了部分 ASR 字面差异，原策略也有同类差异。
配对平均音色相似度从 0.922 降至 0.895；这不是真人听感分数，不能证明下降不可感知。
所有情绪已验证可以生成，但主观自然度、情绪细节和音色仍需试听确认。

## 命令行

平台安装指南会设置对应的 `$Extra`。请在完成安装和模型检查的同一 PowerShell 会话中运行；新开会话时，先按该指南重新设置 `$Extra`。选择参考录音并创建档案后，可用以下命令生成语音：

```powershell
$env:USE_MODELSCOPE = "false"
$env:HF_HUB_OFFLINE = "1"
uv run --no-sync --no-dev --extra $Extra voice-reader speak --text "Hello there." --profile PROFILE_ID
```

把 `PROFILE_ID` 替换为 `voice-reader profiles list` 返回的档案 ID。命令行的档案管理和文本输入方式见 `voice-reader --help`。
内置声音可以使用 `--profile builtin-male` 或 `--profile builtin-female`；
`--language auto` 是默认值，也可指定 `zh`、`en`、`ja`、`es`、`ar`。
`--strength` 默认 0.4。省略 `--profile` 仍使用原来的默认参考录音，保持命令行兼容性。
命令行也默认快速模式；需要情绪控制、发音标注和手动停顿时增加 `--advanced`。

## 本地模型与隐私

模型文件放在 `checkpoints/`，首次初始化使用的辅助模型放在 `checkpoints/hf_cache/`。两处目录都不应提交到 Git。模型下载需要网络；完成预取后，启动器和平台指南会启用离线模式，避免生成期间联网下载。

请遵循 [IndexTTS 上游许可与使用条款](https://github.com/index-tts/index-tts)。
